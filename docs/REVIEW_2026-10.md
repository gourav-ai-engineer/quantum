# External review, October 2026

Source: an external review of PROJECT_STATE.md and the statistics code (QFC_Project_Review.pdf, supplied by
the owner 2026-10-06), recorded here so the critiques stay attached to the project. The reviewer found the
statistics code correct (plain paired bootstrap, percentile Spearman CIs) and the decision rules applied as
written; they could not verify ledger numbers because the result JSONs were not yet in the repository.
Each point is a critique to be answered by an experiment or a wording change, not a result.

## Critiques

1. **Representation ignores the value/output projections.** rho is built from attention weights alone;
   functional redundancy lives in head outputs. Two heads with the same pattern can write different content,
   and different patterns can write redundant content. (Tested by H4 in PROJECT_STATE.md.)
2. **The mean rho averages position-aligned matrices across different sentences.** VNE may measure the
   fixed `[CLS] s1 [SEP] s2 [SEP]` layout rather than content. (Partly supported by our own diagnostic,
   2026-10-06: early-layer VNE rankings are nearly text-independent; see PROJECT_STATE.md V10 follow-up (a).
   Tested by H2 and H3.)
3. **Uniform k per layer handicaps Michel.** The original ranks heads globally with per-layer
   normalisation. Until H6 is run, our Michel is "uniform-k Michel". (H6.)
4. **Accuracy mixes ranking quality with class collapse.** MRPC 0.316 is the minority-class rate (one
   class predicted). Report AUROC and loss as well. (Round 2.)
5. **Underpowered.** One checkpoint per task, 3 seeds, 2 tasks, textattack checkpoints; fine-tuning variance
   is zero by construction; at n=872 the SST-2 error is about +-1 pp, so differences under about 1.5 pp are
   not resolved. (Round 2 adds three new tasks and 5 seeds; fine-tuning-seed variance stays a limitation
   until RoBERTa / own-recipe checkpoints are added.)
6. **The V13 rule ("CI above 0 in 2 of 3 seeds") is not a significance test.** Calibration seeds share the
   same evaluation examples, so they are not independent evidence. The V13 verdict (inconclusive) stands; the
   rule is not reused. Round 2 uses a paired cluster bootstrap over (calibration seed x example).
7. **Bug fixes are reproducibility notes, not contributions.** Correcting our own baselines (Random kept all
   heads; Shannon was NaN under padding) belongs in a methods note.
8. **The independent review must be a human.** Rule 11 needs the supervisor (or another person) reading the
   key code; another Claude session does not count.
9. **The strongest baseline to eventually reproduce** is Kwon et al., NeurIPS 2022, "A Fast Post-Training
   Pruning Framework for Transformers" (Fisher mask search, mask rearrangement, layer-wise reconstruction).
   Citation checked 2026-10-06 against the search result (arXiv 2204.09656); read the primary source before
   citing details.
